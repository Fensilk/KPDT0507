## 三、本会话最重要的方法学发现（务必理解，否则会重复踩坑）

### 发现 1：checkpoint 之间的差异 = 沿前沿滑动，不是能力差异

同一模型的各 ckpt 在 fallen 轴上的 (prec, rec) **几乎完全落在一条陡峭前沿上**
（相关系数 r = −0.955 ~ −0.988），而 `avg_f1` 极差仅 0.035（vs fallen_prec 极差 0.21）。
**单臂内跨 ckpt 的摆动（0.12–0.21）远大于 §7.2 的判定阈值（0.02–0.05）。**

→ **不能用单点比大小判胜负。** 必须扫阈值比**前沿曲线**（同召回下比精度）。

### 发现 2：两个竞争假设都已排除

- **"轮数不够"** ❌：train loss 在约 1 个 epoch 即停降，val 是平带无趋势
- **"学习率未退火"** ❌：a0cos 诊断臂显示 val 带收窄 55% 但 **test 完全没迁移**，
  且 test avg_f1 更差（0.7665→0.7489）、fallen 轴前沿三者最低

### 发现 3：这毛病跨阶段存在，且已量化

单臂内 `avg_f1` 平台段极差：Phase 6 = 0.014–0.071；Phase 8 中位 0.030；E3@2000 = 0.010；E1 = **0.078**。

**受影响的结论**（需降级为"不可分辨"或重算）：
- Phase 8 的个体臂排序与效应量（但**静态轴的定性主张成立**，见下）
- **「E1-full 未超 E1@6000 的 fallen_prec 0.795」**（差 0.044，与 band 同量级）——
  202609 汇报里"不成立全面最优"的表述可能**过严**

**不受影响的结论**（声称"无差异"者是保守的；跨范式大差异远大于 band）：
- Phase 6「三种解码器差 <0.2pp」（band 反而更大，支持更强）
- Phase 5「19 组无一超越默认」
- E1-full vs E3-full `fallen_prec` 差 0.136

### 发现 4：Phase 8 复核结果

| 主张 | 结论 |
|---|---|
| 静态轴（lying→fallen 误报）无改善 | **✅ 成立**（fallen 轴无一臂支配 baseline，全部重叠 ±0.03） |
| "5 特征 × 4 集成全部失败" | **❌ 不成立**（fall 轴 `late_flow` +0.058、`gated_pose` +0.038 **支配 baseline**） |

→ **Phase 9「唯一出路是微调 DINOv2」的支柱（静态轴）完好**，方向未被动摇。
→ 但措辞要改："彻底证伪" → "静态轴未被改善；动态轴上有两变体前沿更优"。

## 五、基础设施与纪律（本会话踩坑换来的）

### 必须遵守的三条

1. **启动前跑 `bash experiments/p11_preflight.sh`**（本地/远端 11 个文件哈希比对，忽略行尾符）。
   本会话曾漏同步 `models/phase9_e1_model.py` → 远端旧版 forward、新脚本传 aux → 崩溃，
   **而我只查了"进程是否存在"就宣布已启动**。
2. **启动后必须等到日志出现 `step ` 行**才算"已启动"。崩溃发生在模型加载后的首个前向（约 5 分钟），
   8 秒的进程检查抓不到。
3. **取子集必须随机**（`--limit_videos` + `--subset_seed`）。
   test.csv 按路径排序、`fall/` 打头：**前 300 个的 fall 帧占比 26.79% vs 全集 6.78%（偏差 +20pp）**。

### 其它已知坑

- **路径**：Git Bash 会把传给原生程序的 `/tmp/...` 自动翻成 `AppData\Local\Temp\...`，
  而 Python 内部打开 `/tmp/...` 得到 `C:\tmp\...` → **跨两者传中间文件必须落在项目内**。
- **校验脚本必须先确认自己在正确目录**：本会话曾在错误目录核对，报出 15 个假的"不一致"
  （`2>/dev/null` 把"文件缺失"和"哈希不符"混成了同一种输出）。
- **长任务四件套**：终止预案、进程级监视（判活用 `/proc/<pid>/stat` 查僵尸，`kill -0` 对僵尸无效）、
  定时进度检查、日志路径 + tail 命令 + 本地镜像。
- **评测成本**：E1 侧全量评测 = **53 min/ckpt**，且是真实 GPU 前向成本（解码仅占 4%，
  批量前向无收益——ViT-g 在 64 帧 batch=1 已吃满 GPU）。
  → best 跑全量、epoch_* 跑固定 300 随机子集。**Phase 8 侧是冻结特征，秒级**。
- **eval 不是逐位确定的**：A0 重评 avg_f1 0.7665→0.7666，有 1e-4 量级运行间抖动。

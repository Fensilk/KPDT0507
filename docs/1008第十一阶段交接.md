## 6. 几条踩过的坑（别再踩）

1. **`setsid nohup ... &` 仍会让 ssh 挂住** → 一切远程启动套 `timeout`
2. **CRLF**：Windows 写的 `.sh` 到 Linux 会 `syntax error` → 传后 `sed -i 's/\r$//'`
3. **`num_workers=16` 的 worker 在 ps 里长得和主进程一样** → 别误判成"重复启动"
4. **同一 ckpt 可能有三份评测 JSON**（`.full.json` / `_model.subset.json` / `eval_epN.json`）→ **按 `n_videos` 取最大**，别按文件名顺序（会误取 300 子集）
5. **`pgrep -f` 会自匹配**自己的 ssh 命令行
6. **判活要看 `/proc/<pid>/stat` 第 3 字段是否为 Z**，不能只 `kill -0`
7. **本机 `python` 直接 `import torch` 会报 OMP duplicate** → 本地跑带 torch 的脚本加 `KMP_DUPLICATE_LIB_OK=TRUE`
8. **`awk '%d'` 在 mawk 下会在 2³¹ 处溢出**：核对大文件时曾显示 `2147483647`（=2³¹−1），
   差点误判成传输截断。**核对文件大小一律用 `stat -c %s`，不要用 `awk printf "%d"`**

# 实验第六阶段规划 — 三分类 + 因果时序建模

## 一、动机

根据混淆矩阵（`logs/phase4/p4a_dino_baseline/confusion_matrix_normalized.png`）：

1. **fall / fallen / lying 三类严重混淆** — 空间特征重叠，模型无法靠单帧区分
2. **standing → walk / stand_up 混淆** — 状态转换的边界模糊
3. **稀有类别模型无法成功学习** — kneel_down, kneeling, squat_down, squatting, crawl, jump 的 F1 接近 0

基于文献调研：跌倒检测的核心任务不是细粒度动作分类，而是**对正在跌倒（fall）、已经跌倒（fallen）、正常状态（normal）三类做出正确判別**，确保不把 fall/fallen 漏报为 normal，不把 normal 误报为 fall/fallen。

## 二、核心改进

### 1. 任务重构：从 16 类多任务到单任务三分类

**旧方案（Phase 4/5）：** 3 头多任务 — 16 类动作分类 + fall 二分类 + fallen 二分类

**新方案：** 单任务三分类 — 将 16 类标签重新映射：

| 三分类标签 | 原始 16 类映射 |
|-----------|---------------|
| **fall** | label == 1 (fall) |
| **fallen** | label == 2 (fallen) |
| **normal** | 其余 14 类：walk, sit_down, sitting, lie_down, lying, stand_up, standing, other, kneel_down, kneeling, squat_down, squatting, crawl, jump |

**为什么做此修改：**
- 消除 Phase 5a 证实的 16 类头 ↔ fall/fallen 头之间的梯度冲突（标量权重 22 个实验均无法解决）
- softmax 互斥性是物理正确的 inductive bias — 一帧不可能同时是 fall 和 fallen
- 模型容量完全服务于跌倒检测
- lying 归入 normal，依赖更强时序建模区分"摔倒后躺着"和"自己躺下"

### 2. 因果时序建模（Causal Temporal Modeling）

**旧方案：** 双向 TransformerEncoder（每帧可以看到窗口内所有帧，含未来帧）

**问题：** 双向注意力在训练时 t_3 帧（fall）能看到 t_8 帧（fallen）—— "作弊"了。部署到实时场景时未来帧不存在，指标虚高。

**新方案：** 因果注意力（只看过去，不看未来），三种候选模块独立替换，三者公平比较：

```
DINOv2 ViT-g (1536d) → Linear(1536→384) → LayerNorm → PE → [Causal Decoder 三选一] → 逐帧三分类 (B,T,3)
```

| 候选 | 配置 | 时间建模方式 |
|------|------|-------------|
| **Causal Transformer** | 1 层, 384d, 6 头, mlp_ratio=4 | 因果自注意力，mask 掉未来帧 |
| **LSTM** | 2 层, 384d | 循环状态传递 H_t = f(H_{t-1}, x_t)，天然因果 |
| **Mamba** | 2 层, 384d, expand=2 | 选择性状态空间模型，天然因果 |

**三者关系：替代关系，不是互补关系。不叠加。** 叠加（如 Causal Transformer + LSTM）会导致梯度路径爆炸、参数冗余、无法消融。

### 3. 窗口扩大：T=32 → T=64

**数据驱动的决策：** 对 12,000 个视频（每视频 80 帧）的完整分析：

| fallen 窗口的完整性 | T=32, stride=8 | T=64, stride=8 |
|--------------------|---------------|---------------|
| 完整（窗口内含 fall 过程） | 43.7% | **79.3%** |
| 残缺（只有 fallen，fall 在窗口之前） | 43.1% | 8.6% |
| 残缺（视频中无 fall） | 13.1%（174 个视频） | 12.0% |

T=32 下超过一半的 fallen 样本为"残局"（人在地上，但看不到怎么倒的），模型没有足够时序信息区分"摔倒后躺着"和"自己躺下"。T=64 将 fallen 完备性从 43.7% 提升至 79.3%，几乎翻倍。样本数从 84K 降至 36K，可接受。

**lying 的 caveat：** 98-99% 的 lying 窗口在任何 T 下都无 fall 前因（lying 视频中根本没有 fall 事件），这是 lying-only 视频本身的结构性特征，非窗口大小能解决。 接受此边界，后续若需改进则考虑额外特征（如姿态关键点）。

### 4. Focal Loss

**问题：** 三分类后 normal 占约 93%，fall/falLen 各约 3-4%。标准交叉熵下，大量 easy normal 帧主宰梯度，模型无动力学好 fall/falLen。

**完整公式：** FL = -α_t · (1-p_t)^γ · log(p_t)

| 参数 | 作用 | 实验取值 |
|------|------|---------|
| γ | 压制 easy 样本（高置信 normal 帧） | {2, 3, 5} |
| α | 类别级别再平衡 | 逆频率自动计算 |

γ=2: 置信度 p_t=0.98 的 easy normal → (1-0.98)² = 0.0004，loss 几乎归零
γ=5: 进一步极端压制，只关心 hard samples

**桥接实验不用 Focal Loss**（维持 CE + pos_weight），确保"三分类"是纯净的单一变量。

### 三分类标签生成逻辑

```python
# 从 16 类标签映射到三分类
# fall → 0, fallen → 1, normal → 2
ternary_labels = np.zeros_like(labels_16)
ternary_labels[labels_16 == 1] = 0  # fall
ternary_labels[labels_16 == 2] = 1  # fallen
ternary_labels[(labels_16 != 1) & (labels_16 != 2)] = 2  # normal
```

### 评估指标

| 指标 | 角色 | 说明 |
|------|------|------|
| **fall_f1 / fallen_f1 / normal_f1** | 主指标，选模型 | 逐帧 per-class F1 |
| **3×3 混淆矩阵**（行归一化） | 诊断指标 | 看 fall↔fallen, fall↔normal, fallen↔normal 的互混模式 |
| **PR 曲线**（per-class） | 报告用 | 展示 precision-recall tradeoff，不设固定 X |
| **桥接对照** | 历史对照 | 与 Phase 4 p4d_vitg 的 fall_f1 / fallen_f1 对比 |

## 五、预期分析

### 主要假设

1. **因果约束会降低 raw 指标，但更诚实。** 双向→因果的 fall_f1 预期下降（去掉"偷看未来"），但因果指标对应真实部署上限
2. **Mamba 有潜力在远时序依赖上优于 Causal Transformer。** Fall→fallen 的转移需要关注特定历史帧（"那一帧开始倒了"），Mamba 的选择性机制可能比全局因果注意力更聚焦
3. **γ=5 可能在这任务上效果最好。** 93% normal 属于极端不平衡，高频 easy normal 帧需要强力压制
4. **桥接实验的 fall_f1 预期低于 Phase 4** — 双向→因果 + T=64（更大窗口/少样本）

### 已有负面证据（不重复实验）

| 已验事项 | 结果 | 结论 |
|---------|------|------|
| 加深 Transformer（p4c_L2, 1L→2L） | fall_f1: 0.660→0.646 | 不加深，保持 1L |
| 标量损失权重调优（Phase 3+5a, 22 实验） | 全部次于 baseline | 不用标量权重，改用 Focal Loss |
| TCN 替代 Transformer（Phase 5b） | 差 ~9pp fall_f1 | LSTM/Mamba 值得试，但 TCN 方向已关 |
| 辅助特征 Δframe/Pose（Phase 4b） | 在有 ViT 下变成噪声 | Phase 6 不加辅助特征 |

| 优先级 | 实验 | 理由 |

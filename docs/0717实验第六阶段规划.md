# 实验第六阶段规划（修订版） — 三分类 + 双向时序建模

## 〇、与原版规划的关系

原版规划引入了**因果约束（causal masking）**——强制帧 t 只能看到过去帧。这个约束未经用户授权，来源于对"实时部署"场景的假设。用户的实际场景允许离线推理（全窗口可见），双向注意力不是作弊，而是可用信息。

**本修订版移除因果约束**，重新设计实验：LSTM 改用 Bi-LSTM，Transformer 保留标准双向注意力。Mamba 因其 SSM 架构天生单向，暂时搁置——且原版因果范式下 Mamba 也未超越 LSTM/Transformer。

## 一、动机

根据 Phase 4/5 混淆矩阵：

1. **fall / fallen / lying 三类严重混淆** — 空间特征重叠，模型无法靠单帧区分
2. **多任务梯度冲突**（Phase 5a 证实）— 16 类头 ↔ fall/fallen 头竞争共享特征，标量权重 22 组实验均无法解决
3. **稀有类别无法成功学习** — kneel_down, kneeling, squat_down, squatting, crawl, jump 的 F1 接近 0

核心问题不是细粒度动作分类，而是**异常检测**——区分"人出事了"和"人正常"。fall 和 fallen 都需要触发响应，二者之间的区分对下游动作没有影响。

## 二、核心改进

### 1. 任务重构：从 16 类多任务到单任务三分类

| 三分类标签 | 原始 16 类映射 |
|-----------|---------------|
| **fall** | label == 1 |
| **fallen** | label == 2 |
| **normal** | 其余 14 类（含 lying） |

软最大互斥是物理正确的 inductive bias——一帧不可能同时是 fall 和 fallen。lying 归入 normal，依赖时序建模区分"摔倒后躺着"和"自己躺下"。

### 2. 双向时序建模（Bidirectional Temporal Modeling）

**不再使用因果约束。** 帧 t 可以看到窗口内所有帧（含未来帧）。部署场景为离线推理，全窗口信息均可使用。

两种时序解码器独立替换，公平比较：

```
DINOv2 ViT-g (1536d) → Linear(1536→384) → LayerNorm → Sinusoidal PE
    → [Bidirectional Decoder 二选一] → Linear(384→3) → (B, T, 3)
```

| 候选 | 配置 | 注意力 | 参数量 |
|------|------|--------|--------|
| **Transformer** | 1L, 384d, 6 头, mlp_ratio=4 | 标准双向自注意力 | 2.37M |
| **Bi-LSTM** | 2L, 384d, bidirectional | 前向+后向隐状态拼接 → Linear(768→384) | 6.80M |

**Mamba 为什么搁置：** SSM 递推 H_t = A_t·H_{t-1} + B_t·x_t 天生单向。在因果范式下的 3 组实验中 Mamba avg_f1 从未进入前 2，且纯 PyTorch 实现的训练速度为 Transformer 的 3 倍。综合性价比不支持继续投入。

**为什么不再比较单向 LSTM：** 单向 LSTM 本质上是一种因果约束（H_t 只依赖 H_{t-1}），与 Bi-LSTM 的差距即因果 vs 双向的差距本身。原版因果实验的 3 组单向 LSTM 已保留作为对照数据。

### 3. 窗口扩大：T=32 → T=64

维持原规划决策。T=32 下 fallen 窗口完备性仅 43.7%（一半以上 fallen 样本看不到倒下的过程），T=64 提升至 79.3%。p6_T32_bridge 消融实验已确认 T=64 全面优于 T=32（avg_f1 +4.1pp）。

### 4. Focal Loss

维持原设计：γ ∈ {2, 3, 5}，α 逆频率自动计算。

但增加一个关键对照：**p6_bridge（双向 Transformer + CE）不引入 Focal Loss**，用于隔离"Focal Loss 本身是否有收益"这一变量。

## 五、预期分析

### 核心假设

1. **双向注意力应显著优于因果约束。** 因果范式下最优 fall_f1 = 0.615，双向范式的 p6_bridge 已经达到 0.684（+6.9pp）。Focal 版本的双向实验至少应维持这一水平。

2. **Bi-LSTM 与双向 Transformer 的差距应该不大。** 因果范式下 LSTM 与 Transformer 的 avg_f1 差距 < 0.5pp。T=64 的序列长度下，Transformer 的全局自注意力和 Bi-LSTM 的双向递推都能充分捕获时序信息，没有先验理由预期一方显著优于另一方。

3. **Focal Loss 的收益可能有限。** Bridge 用 CE 已经达到 avg_f1 = 0.753。如果 Focal 版本不能显著超越这个数字，说明类别不平衡在加权采样 + 三分类简化的框架下已不是主要瓶颈。

### 评估重点

**主指标：异常检测能力（fall+fallen 合并为 abnormal 的召回率/精确率）。** 项目目标是区分"出事了"和"正常"，fall 和 fallen 之间的混淆对下游没有影响。三分类的 fall_f1 / fallen_f1 作为辅助指标保留，但不再独立作为决策依据。

## 3. ⭐ 核心结果：每臂各自相对基线（R3）

> 判定调用**冻结实现** `experiments/judge_w1_arm.py`（与画图同源，未重写）。
> 主判据 = 曲线口径（P@R=0.80 + 支配关系）。

### 3.1 I1 ↔ I2：`p2_1a` vs `p2_anchor`

```
判定：【不确定带 ⚠】
  fall    P@R 0.7187 → 0.7455  (Δ +0.0268)  交叉：低召回端锚点好、高召回端 1a 好；全区间均值 +0.0061
  fallen  0.5997 → 0.6884      (Δ +0.0887)  交叉：方向相反；全区间均值 +0.0531
```

→ **两轴皆交叉**：有优势而**非处处不低**。按冻结条款，**【不确定带】不得据此择优**。
**`1a` 未在不同环境下确立相对基线的支配。**

### 3.2 I1 ↔ I3：`p2_4` vs `p2_anchor`

```
判定：【强通过 ✅】
  fall    0.7187 → 0.7642      (Δ +0.0454)  **本臂支配锚点**（同召回下处处不低，均值 +0.0335）
  fallen  0.5997 → 0.7373      (Δ +0.1376)  交叉；全区间均值 +0.0815
```

→ **`4` 在 fall 轴上 Pareto 支配同批次基线**，两轴均值皆为正 → **【强通过 ✅】**。

### 3.3 两臂独立小结

| | `p2_1a`（I2） | `p2_4`（I3） |
|---|---|---|
| 对基线判定 | **不确定带 ⚠** | **强通过 ✅** |
| fall 轴 | 交叉（+0.0268） | **支配**（+0.0454） |
| fallen 轴 | 交叉（+0.0887） | 交叉（+0.1376） |

⚠ **两行是两条独立结论，不是一条比较的两个名次。** `1a` 未达**不构成**对 `4` 的支持；`4` 通过**也不减免** `1a` 自身需被独立评价的义务。

| 臂（选中） | fall_prec >0.6951 | fall_rec ≥0.8205 | 逐视频 fall_f1 >0.7827 | fallen_prec ≥0.7351 | 逐视频 avg_f1 ≥0.7213 | 通过 |

## 4. 补充参考：`1a` vs `4`（横向比较，**非版本关系**）

> ⚠ 预登记的 R3 只规定"各臂 vs 基线"，**不含臂间直接比较**。本节是**事后补算**的补充参考，
> 用同一冻结实现、同一批 test 数据；**不进入任何一臂的判定**，也不改变 §3 的结论。

```
1a 为"本臂" vs 4（参照=4）                4 为"本臂" vs 1a（参照=1a）
  fall   0.7455 / 0.7642  Δ −0.0186   4 支配（均值 +0.0274）     fall   +0.0186  本臂支配（+0.0274）
  fallen 0.6884 / 0.7373  Δ −0.0489   4 支配（均值 +0.0284）     fallen +0.0489  本臂支配（+0.0284）
  判定：【硬否决 ❌】                                        判定：【强通过 ✅】
```

**事实**：在单点曲线口径下，`4` 在两轴上同时支配 `1a`。

**但这条事实的正确读法**（三句都要）：

1. 它是**横向比较**——衡量的是"这次训练的两个 run 在 test 前沿上谁更高"，
   **不是**"哪个机制更优"的因果结论，也**不是**版本前后关系；
2. `1a` 与 `4` 是**两个独立假设**：**`4` 高不证明 `1a` 的机制错**；**`1a` 未达也不证明 `4` 的机制对**；
3. 【硬否决】这个标签原本是给"臂 vs 基线"设计的，用在臂间属于**外推**——
   有实质意义的是**支配关系本身**（两轴均被 `4` 支配），标签仅供参考。

抖动（5%→20%→50%）在**五项上全部单调劣化**。

### 7.1 验收的口径注记（须随验收一起声明）

`instance` 三项（`fall_prec`/`fall_rec`/`fallen_prec`）在产物里来自
**flat 口径**（`eval_p9e1_dual.py` 把每个窗口的帧全拼接，重叠帧重复计入），
而逐视频两项来自 **voted 口径**（pv 的多窗口均值 + 投票 argmax）。
本验收脚本喂的是 **voted** 数组，故：

- **逐视频两项与产物逐位吻合**（0.7558 / 0.7287 完全一致）→ 同口径，验收即复现；
- **instance 三项口径不同**（本表 0.7252 vs 产物 0.7216）→ 验收的是**同一个指标函数**的行为，
  **不声称复现**那三个数（flat 池化数组未落盘，取不到）。

**→ §7.3 内部混用两个口径，这一点须随指标声明**，否则后人会误以为五项同口径。
（阈值与读数同源：E1-full 的 `instance` 同为 flat 口径，故可比性无碍。）

### 7.2 两道验收的**能力边界**（如实声明）

- **能抓住**本次实际发生的缺陷：键名错 → 读到 `None` → GT 自检绝不可能 5/5；
- **抓不到"类索引串号"**：若把 `fall_prec` 误读为 `precision[1]`（fallen 类），GT 喂入时
  **所有类都是满分**，自检依旧 5/5；负对照数值会变但不必然失败。
  → 这类错误仍需**人工核对字段语义**，不能指望这两道验收。

## 10. 结论

1. **本阶段的核心答案（逐臂独立，各自对基线）**：
   - **`4`（I3，姿态语义）**：对同批次基线**在 fall 轴上 Pareto 支配**，两轴均值皆正 → **【强通过 ✅】**；
   - **`1a`（I2，boundary head）**：对基线**两轴皆交叉** → **【不确定带 ⚠】**，**未确立相对基线的支配**。
2. **两条结论相互独立**：`1a` 未达**不等于**支持 `4`；`4` 通过**也不等于**否定 `1a`（见 §0.2、§4）。
3. **补充参考（非判定）**：单点曲线下 `4` 在两轴上支配 `1a`；但这是**横向比较**，
   不是机制优劣的因果结论，也不是版本关系。
4. **辅读 §7.3 与主判据同向**（2/5 · 3/5 · 5/5），**但其余量 0–0.02 ≪ 落点噪声 0.076–0.179**，
   逐项过/不过基本是抽签，**不构成独立证据**。
5. **随机性（描述）**：`4` 相对锚点的差值符号在两次 anchor 之间**不稳**（k=1/3）；
   同一 anchor 只换 seed，§7.3 通过数即从 3/5 掉到 1/5 —— **落点噪声主导 §7.3** 得到直接实测。
6. **环境（R1）**：val 曲线几乎重合（Δ 均值 −0.0012），但**环境与重跑不可分离，此数不是纯环境效应，也不能当 band**。
7. **主判据只交付了一半**：§2.4（48 ckpt 平均）因数据形态**不可评**（§8 局限 1）。
8. **本实验对「效应 vs 噪声」仍不作答**（无误差棒）；**事件轴的洞照旧登记**。
9. **指标验收已补做并通过**（§7），且**如实声明了它的口径注记与能力边界**。
